问题分析
问题1: bootcmd语法错误
错误：Unknown command 'if'、Unknown command 'then'
原因：bootcmd包含多行if-then-else语法，U-Boot不支持
问题2: boot分区为空
boot分区（分区3）未格式化，内核文件在root分区（分区4）的/boot目录
问题3: 镜像加载失败
Bad Linux ARM64 Image magic! - 从空的boot分区加载了无效数据
修复方案（已执行）
已设置正确的U-Boot环境变量：

setenv load_kernel 'ext4load mmc 0:4 0x00280000 /boot/Image-6.1.115'
setenv load_dtb 'ext4load mmc 0:4 0x03000000 /boot/rk3399-firefly-aio.dtb'
setenv bootargs 'earlycon=uart8250,mmio32,0xff1a0000,1500000n8 root=/dev/mmcblk0p4 rootwait rootfstype=ext4 console=ttyS2,1500000 consoleblank=0 loglevel=7'
setenv bootcmd 'mmc dev 0; mmc rescan; run load_kernel; run load_dtb; booti 0x00280000 - 0x03000000'
saveenv

结果
内核已成功启动：
内核版本: Linux 6.1.115
6个CPU核心全部启动
内存初始化正常
正在等待root设备挂载
系统现在可以自动从root分区加载内核并启动。重启后会使用新的bootcmd自动启动。
